# 7-зертханалық жұмыс: Абстрактілі класс және интерфейс

Интеллектуалды білім беру платформасының объектілік моделі (1-тапсырма).

- `index.html` – сайт (есеп, UML, демо, код)
- `edu_platform.py` – абстрактілі класс, 3 интерфейс, 5 класс
- `main.py` – полиморфизм және 10 тест (`python main.py`)
